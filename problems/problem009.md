# 문자 해독 (애너그램 개수 세기)
[백준 1593](https://www.acmicpc.net/problem/1593)

문자열 W와 S가 주어진다.
모든 문자열은 알파벳으로 이루어지며, 대소문자를 구분한다.

S 안에서 W의 애너그램이 되는 부분 문자열의 개수를 구하라.

# 입력
첫째 줄에 단어 W의 길이 g와 발굴된 벽화에서 추출한 문자열 S의 길이 |S|가 빈 칸을 사이에 두고 주어진다.
둘째 줄에 W,
셋째 줄에 S의 실제 내용이 들어있다.

(`1≤g≤3000`,  `g≤|S|≤3,000,000`)

```
g |S|
W
S
```
```
4 11
cAda
AbrAcadAbRa
```

# 출력
첫째 줄에 W의 순열이 S 안에 있을 수 있는 형태의 개수를 출력한다.
```
정답 (정수)
```
```
2
```
