# RLE 문제 (문자열 압축)

(백준 9935)[https://www.acmicpc.net/problem/9935]

# 입력
문자열S 안에 B가 포함되어 있으면 S에서 B를 제거하고,

이렇게 만들어진 새로운 S에 또 B가 포함되어 있으면 또 S에서 B를 제거한다.

이 방식을 S안에 B가 포함되지 않을 때까지 반복한다.

```
mirkovC4nizCC44
C4
```
```
12ab112ab2ab
12ab
```


# 출력
남은 문자열을 출력한다.
```
mirkovniz
```
남아있는 문자가 없는 경우가 있다. 이때는 "FRULA"를 출력한다.
```
FRULA
```
