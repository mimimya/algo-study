# 연속 문자열 길이 구하기
길이 N인 문자열 S가 주어진다.
문자는 'A', 'B', 'C' 중 하나다.

👉 서로 다른 문자를 최대 K번까지 삭제할 수 있을 때,
하나의 문자로만 이루어진 가장 긴 연속 부분 문자열의 길이 구하여라.


# 입력
첫째 줄에 문자열의 길이 N과 서로 다른 문자를 삭제할 수 있는 개수 K 가 주어진다.
둘째 줄에 문자열 S가 주어진다.
```
N K
```
```
8 2
AABABBAA
```

# 출력
하나의 문자로만 이루어진 가장 긴 연속 부분 문자열의 길이

```
정답 (정수)
```
```
5
```

* `"ABABBA"` → B 두 개 제거 → `"AAAA"` (길이 4)

* `"BABBAA"` → B 두 개 제거 → `"AAAA"` (길이 4)

* `"ABABBAA"` → B 두 개 제거 → `"AAAAA"` (길이 5) ← 최대
